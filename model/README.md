# Model Code and Evaluation

This repository contains the data and Python scripts used for the particle-based transport model developed in my Master's thesis.

A detailed description of the model, its parameter estimation, and the evaluation methods can be found in the thesis.

## Execution Order

The scripts must be executed in the correct order because later steps depend on the results generated by earlier scripts. Running them in a different order may lead to errors or missing results.

**Please run the scripts in the following order:**

1. `01_create_mastertable.py`
2. `02_particle_based_transport_model.py`
3. `03_model_evaluation_metrics.py`

## Script Descriptions

### 1. `01_create_mastertable.py`

This script loads the cleaned tracer experiment data and calculates the breakthrough curve (BTC) metrics used for the analysis and model parameter estimation.

It provides the necessary input data for the subsequent modelling and evaluation steps.

### 2. `02_particle_based_transport_model.py`

This script contains the implementation of the particle-based transport model described in the thesis.

The model represents tracer transport through advection, dispersion, and exchange between different transport states.

### 3. `03_model_evaluation_metrics.py`

This script runs the transport model for the different tracer injections and monitoring stations.

It also calculates the evaluation metrics used to compare simulated and observed breakthrough curves and assess model performance.

## Additional Information

The workflow uses cleaned tracer experiment data as input. Further details regarding the field measurements, data processing, model assumptions, and interpretation of the results are provided in the Master's thesis.
